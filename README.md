# WPF Basics 🚀

A collection of beginner-friendly projects developed using **C#, Windows Presentation Foundation (WPF), and XAML** to practice fundamental WPF concepts, UI design, event handling, and data type conversion.

## 📌 Projects

### 1. Calculator 🧮

A simple calculator application that performs basic arithmetic operations.

**Concepts Covered:**

* WPF UI Design using XAML
* Button Click Events
* Basic Arithmetic Operations
* C# Programming Logic

### 2. Lucky Button 🎯

A simple interactive WPF application that displays a winning message when a button is clicked.

**Concepts Covered:**

* Button Controls
* Event Handling
* `Content.ToString()`
* Dynamic Message Display

### 3. ComboBox & ListBox Basics 📋

A WPF application designed to practice ComboBox and ListBox controls.

**Concepts Covered:**

* ComboBox and ListBox Controls
* Displaying Items
* Item Selection
* Selection Change Events

### 4. Data Type Conversion 🔄

A WPF application demonstrating basic data type conversion using C#.

**Concepts Covered:**

* String to Integer Conversion
* String to Double Conversion
* Number to String Conversion
* String to Boolean Conversion
* `Convert.ToInt32()`
* `Convert.ToDouble()`
* `Convert.ToBoolean()`
* `ToString()`
* Exception Handling using `try-catch`
* Runtime Type Identification using `GetType().Name`

## 🛠️ Technologies Used

* **Language:** C#
* **Framework:** Windows Presentation Foundation (WPF)
* **UI Design:** XAML
* **IDE:** Visual Studio

## 🎯 Purpose

This repository is created to strengthen my understanding of WPF fundamentals through hands-on practice. Each project focuses on specific concepts and helps improve my C# programming skills, UI development knowledge, and event-handling techniques.
